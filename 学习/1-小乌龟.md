# ROS 2 小乌龟 (Turtlesim) 学习

## 一、启动小乌龟

### 1.1 启动容器

```bash
cd /media/wht/N/ROS && ./ros2_ws.sh start
```

### 1.2 启动小乌龟仿真窗口（终端1）

```bash
./ros2_ws.sh turtlesim
```

### 1.3 启动键盘控制（终端2）

```bash
./ros2_ws.sh teleop
```

使用方向键控制小乌龟移动。

## 三、话题 (Topic) 命令

### 3.1 查看话题列表

```bash
ros2 topic list
```

输出：
```
/parameter_events
/rosout
/turtle1/cmd_vel
/turtle1/color_sensor
/turtle1/pose
```

### 3.2 查看话题信息

```bash
ros2 topic info /turtle1/cmd_vel
```

输出：
```
Type: geometry_msgs/msg/Twist
Publisher count: 1
Subscription count: 1
```

### 3.3 实时查看话题数据

```bash
# 查看位置信息
ros2 topic echo /turtle1/pose
```

输出示例：
```
x: 5.544444561004639
y: 5.544444561004639
linear_velocity: 0.0
angular_velocity: 0.0
---
```

```bash
# 查看速度命令
ros2 topic echo /turtle1/cmd_vel
```

### 3.4 查看话题发布频率

```bash
ros2 topic hz /turtle1/pose
```

输出：
```
average rate: 62.482
  min: 0.016s max: 0.017s std dev: 0.00037s window: 64
```

### 3.5 手动发布话题消息

```bash
{
  linear: {
    x: 2.0,   # 前进速度（米/秒）
    y: 0.0,   # 侧向速度（米/秒）
    z: 0.0    # 垂直速度（米/秒）
  },
  angular: {
    x: 0.0,   # 滚转角速度（弧度/秒）
    y: 0.0,   # 俯仰角速度（弧度/秒）
    z: 1.8    # 偏航角速度（弧度/秒）
  }
}
# 控制小乌龟移动（线速度 2.0，角速度 0.0）
ros2 topic pub --once /turtle1/cmd_vel geometry_msgs/msg/Twist "{linear: {x: 2.0, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 0.0}}"

# 控制小乌龟旋转（角速度 1.5）
ros2 topic pub --once /turtle1/cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.0, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 1.5}}"

# 持续发布（按 Ctrl+C 停止）
ros2 topic pub /turtle1/cmd_vel geometry_msgs/msg/Twist "{linear: {x: 2.0}, angular: {z: 0.5}}"
```

## 四、服务 (Service) 命令

### 4.1 查看服务列表

```bash
ros2 service list
```

### 4.2 查看服务类型

```bash
ros2 service type /clear
```

输出：
```
std_srvs/srv/Empty
```

### 4.3 调用服务

```bash
# 清除轨迹
ros2 service call /clear std_srvs/srv/Empty

# 重置小乌龟位置
ros2 service call /reset std_srvs/srv/Empty

# 生成新乌龟
ros2 service call /spawn turtlesim/srv/Spawn "{x: 2.0, y: 2.0, theta: 0.0, name: 'turtle2'}"

# 设置画笔颜色（r, g, b, width, off）
ros2 service call /turtle1/set_pen turtlesim/srv/SetPen "{r: 255, g: 0, b: 0, width: 3, 'off': 0}"

# 传送小乌龟到指定位置
ros2 service call /turtle1/teleport_absolute turtlesim/srv/TeleportAbsolute "{x: 5.0, y: 5.0, theta: 0.0}"
```

## 五、接口 (Interface) 命令

### 5.1 查看接口列表

```bash
ros2 interface list
```

### 5.2 查看消息类型

```bash
# 查看消息定义
ros2 interface show geometry_msgs/msg/Twist
```

输出：
```
# This expresses velocity in free space broken into its linear and angular parts.
Vector3  linear
         float64 x
         float64 y
         float64 z
Vector3  angular
         float64 x
         float64 y
         float64 z
```

```bash
# 查看 Pose 消息
ros2 interface show turtlesim/msg/Pose
```

输出：
```
float32 x
float32 y
float32 theta
float32 linear_velocity
float32 angular_velocity
```

### 5.3 查看服务类型

```bash
ros2 interface show turtlesim/srv/Spawn
```

输出：
```
float32 x
float32 y
float32 theta
string name # Optional.  A unique name will be created and returned if this is empty
---
string name
```

### 5.4 查看动作类型

```bash
ros2 interface show turtlesim/action/RotateAbsolute
```

输出：
```
# The desired heading in radians
float32 theta
---
# The angular displacement in radians to the starting position
float32 delta
---
# The remaining rotation in radians
float32 remaining
```

### 5.5 查找接口包

```bash
ros2 interface package geometry_msgs
ros2 interface package turtlesim
```

## 六、动作 (Action) 命令

### 6.1 查看动作列表

```bash
ros2 action list
```

输出：
```
/turtle1/rotate_absolute
```

### 6.2 查看动作信息

```bash
ros2 action info /turtle1/rotate_absolute
```

输出：
```
Action: /turtle1/rotate_absolute
Action clients: 1
    /teleop_turtle
Action servers: 1
    /turtlesim
```

### 6.3 发送动作目标

```bash
# 让小乌龟旋转到指定角度（弧度）
ros2 action send_goal /turtle1/rotate_absolute turtlesim/action/RotateAbsolute "{theta: 1.57}"
```

## 七、参数 (Param) 命令

### 7.1 查看参数列表

```bash
ros2 param list
```

### 7.2 查看参数值

```bash
ros2 param get /turtlesim background_r
ros2 param get /turtlesim background_g
ros2 param get /turtlesim background_b
```

### 7.3 设置参数值

```bash
# 设置背景颜色（需要先清除轨迹才能看到效果）
ros2 param set /turtlesim background_r 150
ros2 param set /turtlesim background_g 50
ros2 param set /turtlesim background_b 200
ros2 service call /clear std_srvs/srv/Empty
```

## 九、完整演示流程

```bash
# 终端1：启动容器和小乌龟
cd /media/wht/N/ROS
./ros2_ws.sh start
./ros2_ws.sh turtlesim

# 终端2：启动键盘控制

# 查看节点

# 查看话题
ros2 topic list

ros2 topic pub --once /turtle1/cmd_vel geometry_msgs/msg/Twist "{linear: {x: 2.0}, angular: {z: 0.5}}"

# 清除轨迹
ros2 service call /clear std_srvs/srv/Empty

# 生成新乌龟
ros2 service call /spawn turtlesim/srv/Spawn "{x: 3.0, y: 3.0, theta: 0.0, name: 'my_turtle'}"
```

## 十、常用命令速查表

| 命令                                           | 说明             |
| ---------------------------------------------- | ---------------- |
| `ros2 node list`                               | 查看节点列表     |
| `ros2 node info <node>`                        | 查看节点信息     |
| `ros2 topic list`                              | 查看话题列表     |
| `ros2 topic echo <topic>`                      | 实时查看话题数据 |
| `ros2 topic pub <topic> <type> <data>`         | 发布话题消息     |
| `ros2 service list`                            | 查看服务列表     |
| `ros2 service call <service> <type> <data>`    | 调用服务         |
| `ros2 action list`                             | 查看动作列表     |
| `ros2 action send_goal <action> <type> <data>` | 发送动作目标     |
| `ros2 param list`                              | 查看参数列表     |
| `ros2 param get <node> <param>`                | 获取参数值       |
| `ros2 param set <node> <param> <value>`        | 设置参数值       |
| `ros2 interface show <type>`                   | 查看接口定义     |
