# ROS 2 创建工作空间与项目

## 一、工作空间概念

工作空间(Workspace)是包含 ROS 2 软件包的目录，用于组织和构建 ROS 2 项目。

### 1.1 工作空间目录结构

```
ros2_ws/                    # 工作空间根目录
├── build/                  # 编译中间文件（自动生成）
├── install/                # 编译结果：可执行文件、库文件等（自动生成）
├── log/                    # 编译日志（自动生成）
└── src/                    # 源代码目录（手动创建）
    ├── package1/           # 功能包1
    ├── package2/           # 功能包2
    └── ...
```

### 1.2 本项目工作空间

本项目包含两个工作空间：

| 工作空间 | 语言 | 构建类型 | 位置 |
|---------|------|---------|------|
| `ros2_ws` | Python | ament_python | `/media/wht/N/ROS/ros2_ws` |
| `ros2_cp` | C++ | ament_cmake | `/media/wht/N/ROS/ros2_cp` |

## 三、创建软件包

ROS 2 支持三种构建类型的软件包：

| 构建类型 | 适用语言 | 特点 |
|---------|---------|------|
| `ament_python` | Python | 纯 Python 包，简单快捷 |
| `ament_cmake` | C++ | C++ 包，功能强大 |
| `cmake` | C++ | 纯 CMake，不依赖 ament |

### 3.1 创建 Python 软件包

```bash
# 进入 src 目录
cd ~/ros2_ws/src

# 创建 Python 功能包
ros2 pkg create --build-type ament_python \
    --dependencies rclpy std_msgs \
    --node-name talker \
    my_python_pkg
```

**参数说明：**
- `--build-type ament_python`: 指定构建类型为 Python
- `--dependencies rclpy std_msgs`: 指定依赖包
- `--node-name talker`: 自动创建一个名为 talker 的节点入口
- `my_python_pkg`: 包名

**生成的目录结构：**
```
my_python_pkg/
├── my_python_pkg/          # Python 模块目录
│   ├── __init__.py
│   └── talker.py           # 节点源文件
├── resource/               # 资源文件
│   └── my_python_pkg
├── test/                   # 测试目录
│   ├── test_copyright.py
│   ├── test_flake8.py
│   └── test_pep257.py
├── package.xml             # 包描述文件
├── setup.cfg               # setup 配置
└── setup.py                # Python 安装脚本
```

### 3.2 创建 C++ 软件包

```bash
# 进入 src 目录
cd ~/ros2_ws/src

# 创建 C++ 功能包
ros2 pkg create --build-type ament_cmake \
    --dependencies rclcpp std_msgs \
    my_cpp_pkg
```

**生成的目录结构：**
```
my_cpp_pkg/
├── include/my_cpp_pkg/     # 头文件目录
├── src/                    # 源文件目录
├── CMakeLists.txt          # CMake 构建文件
└── package.xml             # 包描述文件
```

### 3.3 package.xml 文件

`package.xml` 是 ROS 2 包的描述文件，定义了包的元信息和依赖：

```xml
<?xml version="1.0"?>
<package format="3">
  <name>example_pkg</name>
  <version>0.0.0</version>
  <description>包描述</description>
  <maintainer email="user@example.com">用户名</maintainer>
  <license>Apache-2.0</license>

  <!-- 构建依赖 -->
  <buildtool_depend>ament_python</buildtool_depend>

  <!-- 运行依赖 -->
  <depend>rclpy</depend>
  <depend>std_msgs</depend>

  <!-- 测试依赖 -->
  <test_depend>ament_copyright</test_depend>
  <test_depend>ament_flake8</test_depend>

  <export>
    <build_type>ament_python</build_type>
  </export>
</package>
```

## 四、编译工作空间

### 4.1 基本编译命令

```bash
# 进入工作空间根目录
cd ~/ros2_ws

# 编译所有包
colcon build

# 推荐：使用符号链接安装（Python 代码修改后无需重新编译）
colcon build --symlink-install
```

### 4.2 常用编译参数

```bash
# 仅编译指定包
colcon build --packages-select my_package

# 编译指定包及其依赖
colcon build --packages-up-to my_package

# 并行编译（指定线程数）
colcon build --parallel-workers 4

# 串行编译
colcon build --executor sequential

# 显示编译详细输出
colcon build --event-handlers console_direct+

# 清除缓存重新编译
colcon build --cmake-clean-cache

# 合并安装目录
colcon build --merge-install
```

### 4.3 本项目编译

```bash
# 使用脚本编译（推荐）
./ros2_ws.sh build

# 或者手动编译
docker exec ros2-humble bash -c "source /opt/ros/humble/setup.bash && cd /root/ros2_ws && colcon build --symlink-install"
```

### 4.4 解决依赖

```bash
# 安装 rosdep（如果未安装）
sudo apt install python3-rosdep

# 初始化 rosdep
rosdep init
rosdep update

# 安装依赖
cd ~/ros2_ws
rosdep install --from-paths src --ignore-src -y
```

## 七、服务通信（Service）

ROS 2 中除了发布/订阅（Topic）通信方式外，还有服务（Service）通信方式。服务是一种**请求-响应**模式的通信机制，适用于需要双向数据交互的场景。

### 7.1 服务概念

| 特性 | Topic（话题） | Service（服务） |
|-----|-------------|----------------|
| 通信模式 | 发布/订阅 | 请求/响应 |
| 数据流向 | 单向 | 双向 |
| 通信频率 | 持续 | 一次性 |
| 参与者 | 多对多 | 一对一 |
| 典型场景 | 传感器数据 | 参数配置、状态查询 |

### 7.2 创建服务端（Python）

**1. 创建功能包（如果需要）**

```bash
cd ~/ros2_ws/src
ros2 pkg create --build-type ament_python --dependencies rclpy example_interfaces service_pkg
```

**2. 创建服务端代码**

创建文件 `service_pkg/service_pkg/service_server.py`：

```python
#!/usr/bin/env python3
import rclpy
from rclpy.node import Node
from example_interfaces.srv import AddTwoInts


class ServiceServer(Node):
    def __init__(self):
        super().__init__('service_server')
        # 创建服务，指定服务类型、服务名和回调函数
        self.srv = self.create_service(AddTwoInts, 'add_two_ints', self.add_two_ints_callback)
        self.get_logger().info('服务端已启动，等待请求...')

    def add_two_ints_callback(self, request, response):
        # 处理请求
        response.sum = request.a + request.b
        self.get_logger().info(f'收到请求: a={request.a}, b={request.b}')
        self.get_logger().info(f'返回结果: sum={response.sum}')
        return response


def main(args=None):
    rclpy.init(args=args)
    server = ServiceServer()
    try:
        rclpy.spin(server)
    except KeyboardInterrupt:
        pass
    finally:
        server.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()
```

**3. 修改 `setup.py` 添加入口点**

```python
entry_points={
    'console_scripts': [
        'service_server = service_pkg.service_server:main',
    ],
},
```

### 7.3 创建客户端（Python）

**1. 创建客户端代码**

创建文件 `service_pkg/service_pkg/service_client.py`：

```python
#!/usr/bin/env python3
import sys
import rclpy
from rclpy.node import Node
from example_interfaces.srv import AddTwoInts


class ServiceClient(Node):
    def __init__(self):
        super().__init__('service_client')
        # 创建客户端，指定服务类型和服务名
        self.client = self.create_client(AddTwoInts, 'add_two_ints')
        
        # 等待服务端启动
        while not self.client.wait_for_service(timeout_sec=1.0):
            self.get_logger().info('等待服务端启动...')
        
        self.get_logger().info('服务端已连接')

    def send_request(self, a, b):
        # 创建请求对象
        request = AddTwoInts.Request()
        request.a = a
        request.b = b
        
        # 异步发送请求
        self.future = self.client.call_async(request)
        return self.future


def main(args=None):
    rclpy.init(args=args)
    
    client = ServiceClient()
    
    # 从命令行参数获取两个整数
    if len(sys.argv) == 3:
        a = int(sys.argv[1])
        b = int(sys.argv[2])
    else:
        a = 41
        b = 1
    
    # 发送请求
    future = client.send_request(a, b)
    
    # 等待响应
    rclpy.spin_until_future_complete(client, future)
    
    # 获取结果
    if future.result() is not None:
        client.get_logger().info(f'请求: {a} + {b}')
        client.get_logger().info(f'响应: {future.result().sum}')
    else:
        client.get_logger().error(f'请求失败: {future.exception()}')
    
    client.destroy_node()
    rclpy.shutdown()


if __name__ == '__main__':
    main()
```

**2. 修改 `setup.py` 添加入口点**

```python
entry_points={
    'console_scripts': [
        'service_server = service_pkg.service_server:main',
        'service_client = service_pkg.service_client:main',
    ],
},
```

### 7.4 创建服务端（C++）

**1. 创建功能包**

```bash
cd ~/ros2_ws/src
ros2 pkg create --build-type ament_cmake --dependencies rclcpp example_interfaces service_cpp_pkg
```

**2. 创建服务端代码**

创建文件 `service_cpp_pkg/src/service_server.cpp`：

```cpp
#include "rclcpp/rclcpp.hpp"
#include "example_interfaces/srv/add_two_ints.hpp"

#include <memory>

class ServiceServer : public rclcpp::Node
{
public:
    ServiceServer() : Node("service_server")
    {
        // 创建服务，指定服务名和回调函数
        srv_ = this->create_service<example_interfaces::srv::AddTwoInts>(
            "add_two_ints",
            std::bind(&ServiceServer::add, this, std::placeholders::_1, std::placeholders::_2));
        
        RCLCPP_INFO(this->get_logger(), "服务端已启动，等待请求...");
    }

private:
    // 服务回调函数
    void add(
        const std::shared_ptr<example_interfaces::srv::AddTwoInts::Request> request,
        std::shared_ptr<example_interfaces::srv::AddTwoInts::Response> response)
    {
        response->sum = request->a + request->b;
        RCLCPP_INFO(this->get_logger(), "收到请求: a=%ld, b=%ld", request->a, request->b);
        RCLCPP_INFO(this->get_logger(), "返回结果: sum=%ld", response->sum);
    }
    
    rclcpp::Service<example_interfaces::srv::AddTwoInts>::SharedPtr srv_;
};

int main(int argc, char **argv)
{
    rclcpp::init(argc, argv);
    rclcpp::spin(std::make_shared<ServiceServer>());
    rclcpp::shutdown();
    return 0;
}
```

### 7.5 创建客户端（C++）

**1. 创建客户端代码**

创建文件 `service_cpp_pkg/src/service_client.cpp`：

```cpp
#include "rclcpp/rclcpp.hpp"
#include "example_interfaces/srv/add_two_ints.hpp"

#include <cstdlib>
#include <memory>

class ServiceClient : public rclcpp::Node
{
public:
    ServiceClient() : Node("service_client")
    {
        // 创建客户端
        client_ = this->create_client<example_interfaces::srv::AddTwoInts>("add_two_ints");
        
        // 等待服务端启动
        while (!client_->wait_for_service(std::chrono::seconds(1)))
        {
            if (!rclcpp::ok())
            {
                RCLCPP_ERROR(this->get_logger(), "等待服务时被中断");
                return;
            }
            RCLCPP_INFO(this->get_logger(), "等待服务端启动...");
        }
        
        RCLCPP_INFO(this->get_logger(), "服务端已连接");
    }

    void send_request(int64_t a, int64_t b)
    {
        // 创建请求对象
        auto request = std::make_shared<example_interfaces::srv::AddTwoInts::Request>();
        request->a = a;
        request->b = b;
        
        // 异步发送请求
        auto result_future = client_->async_send_request(
            request,
            [this, a, b](rclcpp::Client<example_interfaces::srv::AddTwoInts>::SharedFuture future)
            {
                auto response = future.get();
                RCLCPP_INFO(this->get_logger(), "请求: %ld + %ld", a, b);
                RCLCPP_INFO(this->get_logger(), "响应: %ld", response->sum);
            });
    }

private:
    rclcpp::Client<example_interfaces::srv::AddTwoInts>::SharedPtr client_;
};

int main(int argc, char **argv)
{
    rclcpp::init(argc, argv);
    
    auto client = std::make_shared<ServiceClient>();
    
    // 从命令行参数获取两个整数
    int64_t a = (argc >= 3) ? atoll(argv[1]) : 41;
    int64_t b = (argc >= 3) ? atoll(argv[2]) : 1;
    
    client->send_request(a, b);
    
    rclcpp::spin(client);
    rclcpp::shutdown();
    return 0;
}
```
